SYNTHETIC_DEMO_JD / 合成演示岗位说明
岗位：Python 后端开发实习生 / 初级工程师

本材料由项目作者为本地面试陪练演示编写，不来自真实企业招聘公告，不构成招聘邀约、真实雇主要求或已审核评分标准。仅适用于 python-backend-junior 1.0.1 的待审规则与种子范围；正式面试须使用负责人确认的 JD，且岗位包须完成包外负责人两级审核与规则审核。

练习业务：维护一个本地学习记录服务，接收记录、按标题查询并保留数据库内审计行。所有记录、用户和业务情景均为合成数据，不处理真实个人信息。

以下每条是独立要求，避免混合关键词的首条匹配掩盖其他能力。

必要项：
1. 理解 Python 基础与 Python 数据结构，能解释可变默认参数、对象别名、浅拷贝和嵌套对象共享边界。
2. 能说明 HTTP API 创建与读取语义、状态码选择，并区分响应丢失与服务端未执行；重复请求的业务去重须有明确契约。
3. 理解 SQL 事务与数据库事务边界，能在同一 SQLite 连接的工作单元中处理提交与回滚，说明失败残留与竞争条件。
4. 使用参数绑定或参数化查询传入不可信值，理解 SQL 注入风险，区分查询值与排序列/方向等 SQL 结构。
5. 理解 asyncio、事件循环与阻塞调用，能区分异步等待和同步 IO，说明线程卸载的 IO/CPU 适用边界。
6. 编写单元测试并说明异常边界，提出正常值、边界值、非法输入和存储失败的具体断言，不把失败冒充成功。

考察范围：能说明本人负责的代码与未负责部分；区分合成项目设定、口头设计、尚未运行的测试和实际证据。材料没有体现的能力先记为未知，不自动认定不会。

不要求：真实上线经历、性能提升数字、奖项、商业产出、分布式事务、复杂云部署、生产高并发指标、任意数据库驱动知识或全面安全认证。Python 文档以 3.11 为界，SQLite 行为不能直接外推到其他数据库。
