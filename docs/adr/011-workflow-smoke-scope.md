# ADR-011｜M0-02 无模型真实框架验证边界

状态：PROPOSED（仅局部实验；官方基座核验 BLOCKED，未获负责人接受）  
日期：2026-09-18  
关联：M0-01 / M0-02、R19 的框架执行子项、K03 / K17

## 背景与约束

process.md 指定 Workflow smoke；施工计划同时要求官方 WorkflowAgent。现有 openjiuwen==0.1.18 已安装，但前轮临时探针已删除，不能复现。O04 未提供，不能用假模型完成所谓真实模型验证。

## 备选方案

| 方案 | 结果 |
|---|---|
| 仅 Workflow | 覆盖 process.md，但没有验证架构指定 WorkflowAgent 包装入口 |
| Workflow + 单工作流 WorkflowAgent，无 LLM | 选用：真实 SDK 执行；单工作流路由源码明确不调用意图模型 |
| 多工作流路由 + 真实模型 | 缺 O04 配置和费用授权，本轮不做 |

## 局部验证方案（非阶段验收）

独立 smoke 验证两个真实入口；纯文本节点只演示数据传递，不能当作模型、Knowledge 或业务实现。SDK 入口不替换、不 mock；测试可注入明确标记的失败/等待节点，但调度仍由真实 Workflow 完成。所有输入为合成文本。模式 live 只指本地框架，不代表 live LLM。

严格检查状态与预期结果，同时覆盖非法输入、节点错误、超时、重复执行、失败后新运行。不在本任务宣称业务幂等、跨进程状态恢复、模型或知识链路通过。

无依赖、API、Schema、数据库变化。保留 0.1.18 官方 legacy 警告，不修改 site-packages。后续 SDK 升级、需要模型路由或持久恢复时重开。回退为撤销本轮 smoke 与相关文档增量，不动既有环境。Knowledge 后端/embedding 的选择留给 M0-03，未在本 ADR 批准。
