# 产品需求规格 PRD

## 1. 产品边界

目标用户是准备嵌入式软件实习或初级岗位面试的本科生。主要使用场景是项目经历表达和基础技术解释训练。产品不是招聘筛选工具，不生成录用/淘汰/人才等级结论。

Demo 的合理承诺是“针对已提供材料的训练反馈”，不是“验证现实经历真假”或“预测工作能力”。这些边界在界面、报告、计划书中保持一致。

## 2. 用户旅程与需求编号

| ID | 级别 | 用户需求 | 可验收结果 |
|---|---|---|---|
| R01 | P0 | 两个独立入口 | 无简历可整理简历；已有简历可直接面试；不互相强制依赖 |
| R02 | P0 | 导入文本 PDF/粘贴文本 | 保留页/块位置；扫描、损坏、加密、超限有明确提示 |
| R03 | P0 | 确认系统理解 | 关键经历与技能可校正；确认生成新的资料版本 |
| R04 | P0 | 整理简历 | 仅用确认事实重组；显示修改差异；用户接受后才生效 |
| R05 | P0 | 获取简历文件 | 单模板、浏览器打印保存 PDF；文字可选中；长文本不被截断 |
| R06 | P0 | 输入目标岗位 | JD 解析为要求；开始前可核对或重填；没有 JD 时使用标注的演示岗位配置 |

| R08 | P0 | 五道主问题 | 五个不同主问题，至少覆盖三个相关能力维度；每题有来源或明确假设 |

| R12 | P0 | 优化回答 | 改写不添加经历/数据/奖项；缺失内容改为提醒而非编造 |

R08 是产品演示目标；赛事至少五个问题等要求的正式来源见 `docs/14-sources-and-rules.md`，不将本表其他自定要求冒称赛事硬规定。

## 3. P0 成品的严格定义

能使用三份不同合成资料完成完整闭环；五个主问题分别有 ID、目标、材料或 JD 依据、类型与 Rubric。通过其中一份模糊回答的演示，确实触发至少一次有效追问。充分回答测试允许直接换题，不能为了凑官方展示次数制造无意义追问。

每场最多五次补充问题，因此最多十个需要用户作答的展示问题。用户明确结束、技术失败或证据不足时可以提前结束；此时报告标注 incomplete，不能把它作为完整的五题演示验收。

P0 对文本 PDF 的稳定支持优先于 OCR 全覆盖。P0 不提供通用未知岗位自动评分兜底；超范围岗位可仍做经历表达训练，但专业正确性标记为未支持。

## 4. 关键业务约束

- 简历事实修正与简历文案修改分离。改变“负责”到“主导”、增加量化结果、补技术名均属于事实变化，须用户补充并确认。
- JD 缺失项叫“材料未体现”，不叫“能力短板”。未问到的技能不进入弱项记忆。
- 模型名称、框架版本、题库版本、Rubric 版本、资料快照版本固定在一场面试中。
- 面试中改了简历或 JD，不改变当前会话依据；提示新建面试使用新版本。
- 面试时默认不显示标准答案、缺失要点等提示；完成后再展示。观察者演示模式可看来源和动作理由，但要标注，不能与正式无提示评测混用。
- 不以用户学校层次、性别、年龄、身份、照片判断能力；资料中的教育背景只用于经历背景展示。
- 缺少量化指标不普遍扣分。只有题目明确需要、且用户声称提升时，才要求说明基线、口径和测量方式。

## 5. 非功能指标（全部为目标，不是已达成）

| 项目 | 目标/限制 |
|---|---|
| 上传 | 单文件 10 MiB，最多 5 页；单 profile 最多 5 份材料 |
| 总输入 | 每份提取文本最多 30,000 字符，JD 最多 8,000 字符，单回答最多 6,000 字符 |
| 模型调用 | 同时最多 2 个模型请求；单逻辑操作累计最多 3 次模型尝试，含重试与修复 |
| 响应 | 操作受理通常 1 秒内；本地 UI 状态变化 1 秒内；真实模型一轮目标 p95≤20 秒 |
| 耗时上限 | 正常一轮 60 秒，到时明确失败；扫描 OCR 独立 90 秒上限 |
| 会话控制 | 五个主问题、每根问题一次补充；总 15 分钟软预算 |
| 数据 | 单 API 进程，单业务库写入方；每次更新带 expected_revision |
| 稳定性 | 指定验收集不能发生串档、重复扣分、无来源归因、假成功 |
| 容灾 | 刷新重连无需重复调用模型；进程中断后明确 interrupted，不谎称继续执行 |

15 分钟是软预算：默认到时提示继续或结束，不强行替用户提交。测试报告必须写明机器、模型与网络条件；没有足够样本不发布 p95 或效果百分比。

## 6. 范围变更准入

新增功能必须回答：服务哪个 R 编号、带来什么可演示收益、增加几小时、增加哪些失败路径、删掉哪项抵消成本。没有这些信息，不列入当前 Sprint。

最小发布不可删除 R07、R08—R12、R19。P1 不可挤占核心链路与材料时间。报名前仍未完成的项在计划书写“规划/开发中”，而不是用原型图代替实现证据。
