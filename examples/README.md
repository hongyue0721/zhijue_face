# 示例性质和使用限制

全部内容是为解释契约编写的虚构例子，没有真实个人信息；不是应用实测输出、学生回答数据集或已审核题库。

三个种子均为 draft。第三个涉及 RTOS 的题目故意使用待审核参考 ID；施工时补齐具体官方页面、版本、许可与技术审核后才能进入 live。目录里的 JSON 结构合法不意味着题目正确，更不意味着已有 24 道可用题。

两个 Observation 分别演示有表达证据、技术资料不足时不评分。Policy 的 NEXT 示例针对第一条观察，其他事件示例独立，不构成一场完整面试事件流水。

claim 的引文可在 source-blocks.json 找到；观察的引文可在 answers.json 找到。静态检查会验证子串存在，但“引用是否足以支持全部结论”仍需语义审查。

synthetic-resume.txt 和 synthetic-jd.txt 用于起步。后续施工还要准备至少两份不同简历、一份不同 JD，不能仅对本目录姓名或原文特化。
